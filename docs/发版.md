# 发版

小抄版本是注入到微端里的脚本版本。它写在工程根目录 `package.json` 的 `version`，打包后出现在 `xiaochao.js` 头部的 `@version` 和线上清单里。微端自己的版本与此无关，发版时不改、也不看它。

线上清单是 `https://xc.95chong.cn/downloads/manifest.json`。下载页是 `https://xc.95chong.cn/downloads`。客户端按清单里的小抄版本逐段比较，远程更大才提示更新。新版本必须大于当前线上版本，否则已注入旧脚本的客户端不会弹更新，只能手动安装 `wd-xc.zip`。

## 步骤

1. 修改 `d:\workspace\sgs-extension\package.json` 的 `version`。

2. 在 `d:\workspace\sgs-extension` 执行：

```bash
npm run pack
npm run copy:portal
```

`npm run pack` 先用 Vite 构建 `dist/electron/xiaochao.js`，再生成：

| 本地文件 | 含义 |
| --- | --- |
| `release/wd-xc.zip` | 手动安装包 |
| `release/app.zip` | 自动更新包 |
| `release/xiaochao-manifest.json` | 清单，`version` 等于上面的小抄版本，并带 `app.zip` 的 sha256 |

`npm run copy:portal` 把这三个文件拷到 `d:\workspace\portal\public\downloads`。清单在网站上的文件名是 `manifest.json`。

3. 在 `d:\workspace\portal` 执行：

```bash
npm run deploy
```

这一步会 `next build`，再通过 SSH 把站点同步到 `admin@123.56.3.130:/opt/xc/dist`。终端出现「已同步到 admin@123.56.3.130:/opt/xc/dist」后，下载页和清单才是新版本。

## 线上地址

| 地址 | 内容 |
| --- | --- |
| `https://xc.95chong.cn/downloads` | 下载页 |
| `https://xc.95chong.cn/downloads/manifest.json` | 清单 |
| `https://xc.95chong.cn/downloads/app.zip` | 自动更新包 |
| `https://xc.95chong.cn/downloads/wd-xc.zip` | 手动安装包 |
