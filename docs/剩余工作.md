## 1. 删 legacy 前必做

目标：断开 `electron.ts` 对 legacy 的导入后仍能启动，已承诺功能不依赖旧 DOM / `ty()`。

> **不在本节约束内**：自动挂机 / 盖主速刷 / 进阶辅助。它们现在藏在面板里、逻辑还在 legacy；删 legacy 等于暂时没有挂机。以后用 `src/features/` 重做即可，不必先迁完再删。

- [ ] **去掉 `ty()` 钩子硬依赖**：legacy 初始化函数 `ty()` 会给一组固定 `id` 的按钮写 `onclick`（`guanxing`、`redDot`、`goutuo`、`baisheng`、`gamerecord`、`goodsreport`、`pifu`）。这些按钮界面上已藏，但 **节点必须还在**，否则 `ty()` 空引用，整段初始化失败（历史上会连带山河地图也不画）。删 legacy 前要保证：已迁入口只走 Vue；不再执行会盲绑这些 id 的旧初始化。
- [ ] **清空或接管 `settingsHost`**：常规页底部有个空宿主，把 legacy「配置」整页 DOM 挪进来（`moveSettingsPaneIntoGeneralTab`）。开关大多已删/藏，但宿主和残肢节点还在。删 legacy 后没有这份 HTML 可挪，应去掉宿主依赖，常规页只留 Vue。
- [ ] **山河 / 卡牌 legacy pane**：两页旧 DOM 整页 `hidden`，只为让 legacy 初始化不崩。确认新代码不再碰这些节点后删除。
- [ ] **隐藏山河钩子**：`#rogueCitySwitch`、`#openStore` 等标了 `data-migrated-to-vue` 的节点，无 legacy 后删除。
- [ ] **停靠布局语义化收尾**：面板吸到右侧时，要改 `window.padding`、临时改写 `Laya.Browser.clientWidth`、缩 `#bgDiv`，游戏才会重排。现有实现在 `game-layout-docking.ts`，清单里部分仍标依赖 legacy 布局函数（`rX/rP/…`）。删 legacy 前确认整条停靠/拖离/窗口缩放只走新适配器，并防 resize 递归。
- [ ] **生命周期清理补齐**：退出/重载时逆序执行 dispose——卸事件、清定时器、恢复被包装的方法、还原 `clientWidth` getter、关浮层。缺了会漏补丁或漏监听。
- [ ] **`dev:no-legacy` 冒烟通过**：已迁切片在无 legacy 包时可用。
- [ ] **全流程回归**后断开并删除 `src/legacy/xiaochao-legacy.js`。
